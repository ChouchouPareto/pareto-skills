# 目标与阶段判断

## 先判断为何要做

区分行动习惯、表达沉淀、影响力、收入和产品验证。不要让账号自动承担全部目标。问清当前主目标与可以接受的时间、费用和隐私边界；不要求用户先确定终身职业定位。

用以下模型辅助讨论，它是工作假设，不是平台算法公式：

有观看理由 → 看见作者的选择 → 多次兑现预期 → 信任 → 主动回来、推荐或行动。

检查四个独立问题：事情本身是否值得做、内容是否值得看、作者是否值得继续关注、若涉及商业则是否有明确支付与成本结构。差异必须服务于其中一个价值，不为猎奇而猎奇。

## 路线选择

| 路线 | 主要收益 | 主要风险 |
|---|---|---|
| 内容驱动 | 较快试验表达与触达 | 更新压力和热点依赖 |
| 作品驱动 | 实际成果与能力证据 | 做出来不等于讲得清楚 |
| 关系驱动 | 直接反馈与合作信任 | 规模较慢，需同意与边界 |
| 记录驱动 | 启动自然、个人感强 | 容易缺少陌生人的观看理由 |

可组合，不预设作品驱动总是最好。创业意愿、某个生活阶段或所在地不是必须固定的人设。

## 阶段实验

时间与数量由资源决定。可建议六周试验，而非要求执行：

- 前两周：用少量真实素材测试表达形式，建立制作耗时基线。
- 中间两周：重复有潜力的机制，避免只根据一个爆款转向。
- 后两周：结合观众理解、重复互动、个人意愿和实际成本，决定继续、收窄、换形式或暂停。

新形式、合作、长视频、多平台、商业化根据证据进入，而不是达到某个粉丝数自动触发。先保证当前流程可承受，有实际后续内容，再增加负担。对业务需求另行验证，粉丝不能直接当客户。

## 阶段决策

每次调整写清：观察事实、解释假设、其他可能原因、拟调整的一件事、预计观察窗口、何种结果会撤销决定。

可复用的原则：

- 理解差但自己喜欢：先改表达，不直接否定方向。
- 数据好但不愿持续：不为一次成绩绑定长期身份。
- 单条突出：做相关后续检验可重复性。
- 长期高负担：缩短范围、降频或休息，不把压力当动力。
- 仅有计划没有发布：缩成一个低成本可公开产物，不继续扩建系统。
