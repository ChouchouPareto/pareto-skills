# 本地记忆协议

## 存放与授权

工作记忆属于用户，不属于可分发Skill。采用用户指定的私有工作台；不要把个人信息放在技能目录、公开Git仓库、公共模板或外部服务。首次创建时确认路径与可保存范围。若用户已明确要求本地记忆与接续，则可在该范围内维护，简短告知变化。

默认只保存任务相关的目标、偏好、确认决策、任务状态及脱敏反馈。不主动读取无关全局历史；需要旧资料时定向读取获授权的文件。不要保存密码、令牌、身份证、家庭地址、客户信息或私人原始聊天。

## 文件分工

- `memory/profile.md`：用户明确表达的目标、风格、边界与背景；每项标来源与确认状态。
- `memory/state.md`：当前阶段、进行中的工作、卡点、待确认项和下一步。保持短小。
- `memory/decisions.md`：追加日期、决定、依据、适用范围和替代关系；保留旧决策的历史，不把过时状态当当前规则。
- `experiments.md`：内容实验、观察窗口、原始数据位置、解释与结论。不存在实验时明确写尚未开始。

## 写入规则

区分：用户已明确、用户自述经历、助手建议待确认、观测结果、过时/被替代。

例：“用户目前不喜欢连续出镜口播”是明确偏好；“用户内向”是未经支持的心理推断，不应保存为事实。

用户说“整体可以”不代表同意具体发布日历。保存成“认可总体方向，细则待确认”。只有真正完成并核实的产物才从待办改为完成。

对明确纠正及时更新当前文件并记录替代条目；不在用户未同意时把公开身份、受众、商业目标做重大修改。每次只写本轮差异，避免复制整段聊天。

## 安全与可携带性

发布技能前检查Git差异，只上传通用方法和空白模板。不能因为有.gitignore就认为已追踪内容不会上传。个人档案禁止进入公开提交。

用户要求忘记时，移除指定记忆并核对其他本地副本；用户要求连历史一起删除时不保留含原信息的删除日志。说明无法保证删除已存在的备份或外部副本，不声称全局遗忘。

路径不可访问、上下文冲突、记忆损坏时停止猜测，说明缺口。仅能从当前可读文件恢复，不宣称自动获得所有对话。会话末尾回读实际写入字段，确认后再说已保存。
